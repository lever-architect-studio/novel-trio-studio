# Novel Trio Studio（日本語版）

> **物語は、一直線には完成しない。分岐し、戻り、比べ、削り、また選ぶ。**  
> **Novel Trio Studio** は、**「続ける」「リトライ」で生み出した膨大な候補・分岐・名文を1つも捨てずにローカルへ残し、いつでも比較して「純粋な確定本文」へ戻せる** 3ペイン構成のローカル完結型 AI 小説執筆スタジオです（KoboldCpp 等ローカルLLM対応）。

[English README](README.md) · [Waitlist 登録ページ](https://lever-architect.com/novel-studio/) · [開発アカウント (@MyAinoveLib)](https://x.com/MyAinoveLib)

## なぜこのスタジオを作ったのか

「ちょっと小説を書いてみようかな」「途中で行き詰まったな」「次にどう展開したらいいか読者や編集者に相談したいけど、今は聞ける相手がいない」——ひとりで書いていると、頭の中がモヤモヤしたまま手が止まりがちです。

**Novel Trio Studio** は、AI とさらっとやり取りしているうちに **自分の頭の中がだんだんクリアになり、次々とアイデアが浮かんでくる「壁打ち・共創」の体験** と、**そこで生まれた膨大な候補・名文を1つも捨てずに物語へ戻せる仕組み** を両立させるために作りました。

- **モヤッとした思いつきが、やり取りするうちに形になる** — テーマ→あらすじ→キャラ→起承転結の対話や「執筆前・演出相談」「3方向プロンプト補助」で壁打ちするうちに、書きたい展開が自然に見えてきます。
- **浮かんだ名文や分岐を絶対に埋もれさせない** — 「続ける」「リトライ」を何十回も回して掘り当てた最高の一文が、次の生成で消えたり、`作品_01-02-別案その3.txt` の山に埋もれたりしません。
- **試行錯誤と本文を混ぜない** — プロンプトの相談と作品の本文が同じチャット欄にごちゃ混ぜにならないため、そのまま純粋な原稿として積み上がります。

**Novel Trio Studio** は、この一連の流れを「汎用チャットUIの延長」ではなく **小説家のための3ペイン専用ワークステーション** として実現しています。

## Novel Trio Studio だけの強み

### 1. 何も失わない非破壊分岐 ＋ 裏で最大30案を回す「サイレント別案生成」
- **全ターンが非破壊の分岐ツリー**: どのターンからリトライ・編集しても、それ以降の続き（下流のシーン群）を丸ごと保持したまま別ルートへ分岐し、`◀ / ▶` でいつでも行き来できます。
- **サイレント別案ループ（1〜30回）**: 指示を固定したまま、裏側（バックグラウンド）で最大 **30個の別案候補** を静かに生成・蓄積。いま読んでいる画面を邪魔せず、あとから「あの言い回しやっぱり良かった」を比較して選べます。
- **続き生成の2色ハイライト差分**: 「続き」を生成したとき、既存本文と新しく生成された文章を別色で表示するため、繋ぎ目の違和感を一目でチェックできます。

### 2. 3ペイン完全分離：プロット共創 × 執筆・分岐 × 純粋な確定本文
プロンプトの試行錯誤を、完成原稿に一切混ぜません。
1. **左ペイン：プロット共創（4段階ゲート設計）**  
   テーマ → あらすじ（200〜300字） → キャラクター自動抽出（常時注入 `Memory` とキーワード発動 `World Info` へ自動仕分け＋個別深掘り） → 起・承・転・結4ボックス構成。さらに **Zoom-In Deep Dive** で特定の1シーンだけを5倍の解像度で深掘りできます。
2. **中央ペイン：執筆ストリーム＆演出相談**  
   カード単位で直接編集・`📌 小説本文に追加`・`🔄 別案`・`✍️ 続き` を操作可能。書く前に専用モーダルで演出を詰める **執筆前・演出相談** や、**3方向プロンプト補助（心理・五感 / 展開・テンポ / 描写・ギミック）** も備えています。
3. **右ペイン：純粋な確定本文 ＋「確定本文 → WI記憶化」**  
   採用（ピン留め）した文章だけが入るクリーンな原稿スペース。さらに **「確定本文 → WI記憶化」** ボタン1つで、書き上げた章の事実や約束を構造化 World Info へ自動圧縮し、長編でも設定矛盾を防ぎます。

### 3. コンテキスト・World Info・トークンの完全可視化
- **AND条件付き・3段階強度の World Info**: 通常のORキーワードだけでなく **AND必須キーワード（複数条件が揃った時だけ発動）** や、注入位置・強度（背景・通常・強）まで細かく制御できます。
- **リアルタイム発火インジケーター**: プロンプトを入力しているその瞬間に、「いまどの World Info とキャラが発火しているか」がバッジで光って見えます。
- **スコープ制御＆DRY/XTC最適化**: 「今の『承』のシーンだけ渡す」「このキャラは今回オフ」などをワンクリックで切り替え、ローカルLLM向けの **DRY / XTC / Heat** スライダーも搭載しています。

### 4. リサーチ・PDF資料ライブラリ・文体DNA抽出（外部APIキー不要）
- **PDF資料取り込み＆文体DNA抽出**: 縦書き/横書き日本語 PDF や OCR に対応し、類語展開で参考シーンを検索したり、文体の特徴（Style DNA）を抽出して再利用できます。
- **逆算プロット抽出**: 既存の小説・草稿を読み込ませて、起承転結・キャラ・テーマ・あらすじを左ペインへ逆算抽出できます。
- **外部API不要のディープ検索 → チートシート化**: 設定考証用の調査結果を自動整理し、そのままプロンプトで使えるチートシートとして保存できます。
